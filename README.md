# Shkurtues Linkesh 🔗

Shkurtues linkesh me slug custom dhe statistika klikimesh — 100% lokal, pa server.

**Live:** https://erionnezha.github.io/Link-Shortener/

## Veçori

- 🔗 Shkurto URL të gjata me slug të personalizuar (format: `…/#s=slug`)
- ✅ Validim: URL duhet të fillojë me `http://`/`https://`; slug vetëm `[a-z0-9-]`, min. 3 karaktere, unik
- 📋 Buton **Kopjo** për çdo link
- 📊 Numërues klikimesh për çdo slug
- 🔀 Ridrejtim automatik: hapja e `/#s=slug` rrit numëruesin dhe ridrejton te URL-ja origjinale
- 🗑 Fshirje linkesh individuale
- 💾 Gjithçka ruhet në `localStorage` — asnjë e dhënë s'dërgohet askund
- 📱 Responsive, UI plotësisht në shqip

## Demo lokale

Badge në faqe e bën të qartë: linket funksionojnë brenda kësaj faqeje dhe ruhen në shfletuesin tënd.
